# ADR 0002: حدود حزمة المزامنة (Sync Package Boundary)

# الحالة
مقبول

# السياق
النظام يعمل بمبدأ "الأولوية للعمل دون اتصال" (Offline-first)، وهو مقسم حسب الولاية والوحدة، ويتبادل البيانات عبر سير عمل التصدير والاستيراد. بدون وجود حدود صريحة، قد يصبح أي تنسيق ملموس (مثل ملفات CSV أو الكتل المشفرة) هو بروتوكول المزامنة الفعلي، مما يؤدي لربط حالات الاستخدام بآلية النقل ويجعل التغييرات المستقبلية (مثل التوقيع أو الإصدارات) مكلفة للغاية.

# القرار

1.  **طبقة التطبيق (Application Layer):** تحدد حصراً "غلاف التبادل الدلالي" (Semantic Interchange Envelope): `SyncPackage<T>`، و `SyncPackageMetadata`، و `PackageId`، و `SyncPackageKind` مع ثابت إصدار المخطط (`SYNC_PACKAGE_SCHEMA_VERSION`). هذا يمثل "ما الذي ينتقل بين العقد" برمجياً، وليس كيفية ترميزه على القرص.
2.  **طبقة البنية التحتية (Infrastructure Layer):** تمتلك خطوات الترميز والحماية التي تحول ذلك الغلاف إلى بايتات غير واضحة:
    *   المسلسل (Serializer): يحول `SyncPackage<T>` إلى بايتات نصية (حالياً JSON).
    *   `PackageBuilder`: يجمع بين التسلسل (Serialization) و `ExportPayloadEncryptor` (مثل تشفير age) ويعيد بايتات فقط.
    *   الاستمرارية/التسليم: يتم استخدام `ExportFileSink` بعد عملية التغليف.
3.  **CSV ليس بروتوكول المزامنة:** تظل ملفات CSV وسيلة للعرض أو التقارير فقط. مسار تبادل الملخص الشهري يستخدم غلاف JSON `SyncPackage<MonthlySummaryExportDataset>` مع التشفير، واستخدام امتداد `.sync` كإشارة للملف على القرص.
4.  **الاستيراد:** يعكس عملية التصدير: فك التشفير ← JSON نصي ← التحقق من الحزمة (إصدار المخطط، المعرف، الشهر، البيانات) ← المطابقة مع `MonthlyReport`.
5.  **حزم المنتجات:** تتبع نفس الحدود؛ حيث يتم تصديرها من الولاية واستيرادها في الوحدة مع سياسة ملكية صارمة (يجب أن يطابق `source_node_id` كود الولاية للمستورد).
6.  **حزم التقارير اليومية:** تتبع نفس الحدود والسياسات الخاصة بالولاية والوحدة.
7.  **حماية الإعادة (Replay Guard):** يتم استخدام جدول `applied_sync_packages` لتخزين معرفات الحزم المستوردة لمنع التكرار (Idempotency) ضمن نفس المعاملة (Transaction).

# النتائج المترتبة
*   تستمر حالات الاستخدام في إعادة مجموعات بيانات دلالية (Semantic Datasets) دون الاهتمام بتفاصيل التشفير أو التسلسل.
*   استبدال JSON بتنسيق ثنائي أو إضافة ضغط لا يتطلب إعادة كتابة حالات استخدام قراءة الملخص الشهري.
*   سير العمل القديم الذي يفترض وجود ملفات CSV مشفرة لن يكون متوافقاً مع المسار الجديد المعتمد على `.sync`.
