# ADR 0001: سياسة استخراج طبقة القراءة (Read Layer Extraction Policy)

# الحالة
مقبول

# التاريخ
2026-05-09

# السياق
بدأ النظام البرمجي الخلفي (Backend) باستخدام عمليات قراءة تعتمد على المستودعات (Repositories) مع مطابقة مباشرة لـ SQL مع الكيانات (Entities). ومع نمو متطلبات التقارير والتصدير، قمنا بتقديم استعلامات قراءة وتوقعات (Projections) متخصصة:

*   `MonthlyWindow`: للتعامل مع الحدود الزمنية للشهر.
*   `MonthlySummaryProjection`: لتشكيل قراءة الملخص الشهري والتفاصيل.
*   `WilayaReportProjection`: لتقارير مستوى الولاية (Denormalized).

هذه الخطوات حسنت الاتساق وتجنبت نمط "جلب الكل ثم التصفية"، ولكنها قدمت خطراً جديداً: الاستخراج المبكر لأدوات مساعدة أو أطر عمل عامة تقلل من عدد أسطر الكود (LOC) دون تقليل المخاطر الدلالية (Semantic Risks).

# القرار
يتم إدراج الأدوات المساعدة أو التوقعات (Projections) أو التجريدات (Abstractions) في طبقة القراءة فقط عند تحقق واحد على الأقل من الشروط التالية:

1.  **وجود تكرار دلالي**: (تكرار نفس المعنى البرمجي أو معنى القراءة في أماكن متعددة).
2.  **ظهور خطر الانحراف (Divergence)**: (احتمال اختلاف سلوك مسارات الكود البرمجي المختلفة مع الوقت).
3.  **وجود أكثر من مستهلك فعلي**: يحتاج إلى نفس سلوك القراءة (مثل واجهة برمجة التطبيقات + التصدير).

تقليل عدد أسطر الكود (LOC) وحده ليس مبرراً كافياً للاستخراج.

# النتائج المترتبة

## الإيجابيات
*   تظل استعلامات SQL والقدرة على القراءة صريحة وسهلة التتبع.
*   تظل الملكية واضحة (طبقة `application` تنسق، وطبقة `infrastructure/db/read` تشكل عمليات القراءة).
*   منع الانتشار المبكر لأطر الاستعلامات والأدوات المساعدة.
*   إبقاء عمليات إعادة الهيكلة (Refactoring) تدريجية وقابلة للتراجع.

## المقايضات (Trade-offs)
*   يتم قبول بعض التكرار النصي بشكل متعمد.
*   قد تظل استعلامات SQL متكررة قليلاً حتى يصبح الضغط حقيقياً.
*   قد تستمر عمليات المطابقة المحلية الصغيرة عند حدود المحولات (Adapters).

# إرشادات عملية
*   تفضيل التوقعات (Projections) المسطحة والمتخصصة والموجهة للقراءة في حالات التقارير الثقيلة.
*   عدم تقديم بناة استعلامات عامة (Generic Query Builders) أو أطر عمل للمواصفات بشكل افتراضي.
*   إعادة تقييم الاستخراج فقط عند ملاحظة تكرار دلالي أو خطر انحراف.
