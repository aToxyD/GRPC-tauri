# ADR 0014: ذكاء معالجة تعارضات المزامنة (Sync Conflict Intelligence)

# الحالة
مقبول

# السياق
احتاج النظام إلى آلية لاكتشاف وإدارة التعارضات التي تنشأ أثناء عملية المزامنة بين العقد المتعددة.

# القرار
تنفيذ آلية تتبع التعارضات في `repositories/sync_conflicts.rs`.

### أنواع التعارضات
| النوع | الوصف |
| :--- | :--- |
| `STALE_IMPORT` | الحزمة أقدم من الطابع الزمني لآخر مزامنة معروفة. |
| `DUPLICATE_PACKAGE` | معرف الحزمة مسجل مسبقاً في `sync_applied_packages`. |
| `OUT_OF_ORDER_REPORT` | تاريخ التقرير يسبق تاريخ آخر تقرير مستورد. |
| `DIVERGENT_STOCK_STATE` | المخزون المحسوب ينحرف عن الحالة الواردة في التقرير. |
| `REPLAY_ATTEMPT` | تم استخدام Nonce أو بصمة الحزمة مسبقاً. |

### مستويات الخطورة
*   **CRITICAL**: خطر على سلامة البيانات (Integrity).
*   **ERROR**: فشل تشغيلي.
*   **WARNING**: اكتشاف شذوذ (Anomaly).

### سير عمل الحل (Resolution Workflow)
1.  يقوم المشغل بعرض التعارض في صفحة مركز التعارضات.
2.  مراجعة الوصف والحل المقترح.
3.  إدخال ملاحظة الحل والتأكيد.
4.  يقوم أمر `resolve_sync_conflict` بتحديث الحالة وتسجيل العملية في سجل التدقيق.

### التفويض (Authorization)
*   `Action::ViewSystemHealth`: للعرض فقط.
*   `Action::ManageSyncConflicts`: للحل (للمسؤول فقط).

# النتائج المترتبة
*   تمكين المشغلين من اكتشاف وحل شذوذ المزامنة عبر واجهة المستخدم.
*   تسجيل كافة إجراءات الحل في سلسلة التدقيق (Audit Chain).
*   دمج عملية اكتشاف التعارضات ضمن مسار الاستيراد (Import Pipeline).
