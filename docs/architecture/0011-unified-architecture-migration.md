# ADR 0011: الهجرة المعمارية الموحدة (Unified Architecture Migration)

# الحالة
مقبول

# السياق
كان المشروع في حالة "معمارية انتقالية هجينة"؛ حيث كان منطق التفويض (Authorization) مقسماً بين الحراس القدامى (Guards) والسياسات الجديدة، وكانت الخدمات مشتتة بين مجلدي `services/` و `application/usecases/`. أدى ذلك إلى زيادة أعباء الصيانة وارتباك معماري.

# القرار
تقرر توحيد المعمارية تحت مسمى "المعمارية الموحدة المستقرة" من خلال:
1.  نقل كافة منطق العمل والتنسيق من الأوامر (`commands/`) إلى طبقة مركزية في `application/services`.
2.  تهجير كافة قرارات التفويض إلى سياسات `application/authz`.
3.  تحويل `commands/guards.rs` إلى غلاف نحيف لإدارة الجلسات والبوابات الأساسية فقط.
4.  تقوية فرض الحدود المعمارية باستخدام `scripts/check_arch.ts`.
5.  فرض مبدأ أن الأوامر تقوم فقط بتحليل المدخلات، التفويض، استدعاء الخدمات، ومطابقة النتائج.

# النتائج المترتبة
*   فصل صارم للمسؤوليات (Separation of Concerns).
*   نموذج أمني موحد.
*   سهولة اختبار منطق العمل دون الاعتماد على تبعات Tauri.
*   هيكل مشروع أكثر وضوحاً وتقليل التكرار.
