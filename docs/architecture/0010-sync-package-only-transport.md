# ADR 0010: طبقة النقل الموحدة القائمة حصراً على حزم المزامنة

# الحالة
مقبول

# السياق
كانت الإصدارات السابقة تسمح بمزامنة البيانات عبر ملفات CSV إلى جانب تنسيق `SyncPackage`. أدى ذلك إلى ارتباك تشغيلي، وثغرات أمنية (ملفات CSV لا تدعم السلامة أو التوقيع)، ومشاكل في اتساق البيانات بسبب نقص حماية الإعادة (Replay Protection) في استيراد الملفات الخام.

# القرار
1.  **إلغاء وإزالة مزامنة CSV**: تم حذف كافة مسارات الكود التي كانت تسمح باستيراد أو تصدير كيانات قاعدة البيانات للمزامنة عبر CSV.
2.  **البروتوكول الموحد**: أصبح تنسيق حزمة المزامنة (`.sync`) هو **طبقة النقل القياسية والوحيدة** لتبادل البيانات بين العقد.
3.  **فصل المسؤوليات**:
    *   **حزمة المزامنة**: لمزامنة النظام مع النظام (موثقة، مشفرة، وذات إصدارات).
    *   **Excel**: للاستهلاك البشري (التقارير، التدقيق، والطباعة). لا يُسمح بإدخال أي بيانات للنظام عبر Excel.

# المبررات
*   **الأمن**: توفر حزمة المزامنة تشفيراً متدفقاً (age-encrypted) وموثوقية تعتمد على HMAC.
*   **الموثوقية**: تتضمن البيانات الوصفية للحزمة معرفاً فريداً (`package_id`) يسمح بإجراء فحوصات تكرار قوية (Anti-replay).
*   **قابلية الصيانة**: تقليل التعقيد المعماري ومنع "انحراف التنسيق" من خلال الحفاظ على بروتوكول واحد ذو إصدارات (Schema V2).

# النتائج المترتبة
*   لا يمكن للمستخدمين "تعديل" ملفات المزامنة يدوياً (وهي ميزة أمنية مقصودة).
*   يجب تحديث أدلة التشغيل لتعكس أن ملفات `.sync` فقط هي الصالحة للنقل.
*   ستتوقف أي سكربتات أتمتة قديمة كانت تعتمد على تصدير CSV لأغراض المزامنة.
