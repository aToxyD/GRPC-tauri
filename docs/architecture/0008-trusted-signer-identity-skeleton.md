# ADR 0008: سياسة هوية الموقع الموثوق (Trusted Signer Identity Policy)

# الحالة
مقبول

# السياق
التوقيع الصالح لا يضمن بالضرورة أن الموقع موثوق به بالنسبة للعقدة الحالية.

# القرار
تنفيذ قائمة سماح للموقعين الموثوقين تعتمد على متغيرات البيئة:

1.  `GRPC_TRUSTED_SIGNER_IDS`: قائمة مفصولة بفاصلة لمعرفات العقد المسموح لها بإرسال الحزم.
2.  `GRPC_ENFORCE_TRUSTED_SIGNERS`: إذا كانت القيمة "صحيحة" (true)، فسيتم قبول الموقعين المدرجين في قائمة السماح فقط.

# النتائج المترتبة
*   التمييز بين التوقيع الصالح تقنياً وبين المصدر الموثوق تشغيلياً.
*   تمكين التحكم التشغيلي في الوحدات التي يمكنها المزامنة مع الولاية.
