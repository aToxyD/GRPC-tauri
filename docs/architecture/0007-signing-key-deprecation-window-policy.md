# ADR 0007: سياسة نافذة إهمال مفاتيح التوقيع (Signing Key Deprecation Window Policy)

# الحالة
مقبول

# السياق
تحتاج الفرق إلى وسيلة لإيقاف استخدام المفاتيح القديمة بأمان أثناء عملية النشر عبر العقد التي تعمل دون اتصال.

# القرار
تنفيذ سياسة نافذة الإهمال (Deprecation Window):

1.  `GRPC_DEPRECATED_SIGNING_KEY_IDS`: قائمة بمعرفات المفاتيح المراد إحالتها للتقاعد.
2.  `GRPC_SIGNING_KEY_DEPRECATION_DEADLINE_UTC`: الموعد النهائي (تنسيق RFC3339) الذي لن يتم بعده قبول هذه المفاتيح.

# النتائج المترتبة
*   يمكن أن يتوفر تداخل مؤقت للمفاتيح لضمان التوافق أثناء التدوير.
*   يتم فرض التقاعد بشكل حتمي بمجرد تجاوز الموعد النهائي.
*   تظل السياسة بسيطة وتعتمد على متغيرات البيئة.
