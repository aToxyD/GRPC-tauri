# ADR 0006: سياسة تدوير مفاتيح التوقيع (Signing Key Rotation Policy)

# الحالة
مقبول

# السياق
يتطلب بروتوكول المزامنة وسيلة لتدوير مفاتيح التوقيع (HMAC) دون الحاجة إلى بنية تحتية معقدة.

# القرار
اعتماد سياسة تدوير بسيطة باستخدام متغيرات البيئة:

1.  **مفتاح التوقيع النشط** (`GRPC_ACTIVE_SIGNING_KEY_ID`): يستخدمه المصدرون (Exporters) لوسم الحزمة بمعرف المفتاح المستخدم.
2.  **مفاتيح التحقق المقبولة** (`GRPC_ACCEPTED_SIGNING_KEY_IDS`): قائمة مفصولة بفاصلة من معرفات المفاتيح التي سيقبلها المستورد لغرض التحقق.

# النتائج المترتبة
*   يتم التدوير عن طريق تحديث متغيرات البيئة عبر كافة العقد.
*   يتم رفض الحزم الموقعة بمفاتيح غير مقبولة.
*   لا يوجد توزيع آلي للمفاتيح؛ يجب إدارتها يدوياً من قبل المشغل.
