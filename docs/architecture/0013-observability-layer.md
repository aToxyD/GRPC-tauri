# ADR 0013: طبقة قابلية المراقبة (Observability Layer)

# الحالة
مقبول

# التاريخ
2026-05-11

# السياق
وصلت منصة GRPC-tauri إلى حالة "المعمارية الموحدة المستقرة" مع تطبيق المعمارية السداسية (Hexagonal Architecture)، وتوحيد التفويض (Authz)، وحزم المزامنة الموقعة والمشفرة، وحماية الإعادة لسلسلة التدقيق. ومع ذلك، كان المشغلون يفتقرون للرؤية التشغيلية حول:
*   سلامة سلسلة التدقيق (اكتشاف كسر البصمات أو التلاعب).
*   صحة النظام (قاعدة البيانات، حداثة النسخ الاحتياطية، التخزين).
*   صحة عقد المزامنة (المقاييس لكل عقدة، الحزم المرفوضة).
*   إحصائيات التعارضات.

# القرار
تقديم **طبقة قابلية مراقبة تشغيلية** للقراءة فقط تتكون من:

### الخدمات الخلفية (Backend Services)
*   `audit_observability_service`: للتحقق من السلسلة وإعداد تقارير الحالة.
*   `system_health_service`: لتجميع حالة المكونات المتعددة.
*   `sync_conflict_service`: لاكتشاف وتسجيل وحل التعارضات.

### المستودعات الجديدة
*   `repositories/sync_conflicts`: للوصول إلى جدول `sync_conflicts` عبر SQL.

### الأوامر الجديدة (Commands)
*   `get_audit_chain_status`: يعيد حالة التحقق من السلسلة.
*   `get_audit_health`: تقرير كامل عن الصحة مع كشف الشذوذ (Anomalies).
*   `get_system_health`: تقرير صحة كافة المكونات.
*   `get_sync_health`: مقاييس الصحة لكل عقدة.
*   `get_conflict_summary`: إحصائيات مركز التعارضات.
*   `list_sync_conflicts`: قائمة التعارضات القابلة للتصفية.
*   `resolve_sync_conflict`: حل التعارض من قبل المشغل مع توثيقه في سجل التدقيق.

### صفحات واجهة المستخدم (Frontend)
*   `AuditIntegrityPage`: حالة السلسلة، عرض البصمات، وقائمة الشذوذ.
*   `SystemHealthPage`: بطاقات صحة المكونات + جدول لكل عقدة.
*   `SyncTopologyPage`: رسم بياني للشبكة ومخططات تفصيلية.
*   `ConflictCenterPage`: الجدول الزمني للتعارضات، التصفية، ونافذة الحل.

### القواعد المعمارية المضافة (check_arch.ts)
*   **القاعدة 22**: لا يسمح بمنطق التسوية داخل الأوامر؛ يجب استخدام الخدمات.
*   **القاعدة 23**: لا يسمح بـ SQL داخل ملفات محول الواجهة الأمامية.
*   **القاعدة 24**: يجب إقران حل التعارض بسجل التدقيق.

# النتائج المترتبة
*   **الإيجابيات**: رؤية تشغيلية كاملة دون تعديل السلوك الحالي، الالتزام التام بالمعمارية السداسية، وتوثيق كافة إجراءات التسوية في سجلات تدقيق غير قابلة للتعديل.
*   **المقايضات**: يتطلب جدول `sync_conflicts` هجرة بيانات (Migration 002) وهي هجرة إضافية دون أي تغييرات جذرية.
