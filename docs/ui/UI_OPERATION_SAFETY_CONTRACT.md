# عقد سلامة العمليات لواجهة المستخدم (UI Operation Safety Contract)

# الهدف
يحدد هذا المستند الضمانات الحتمية (Deterministic) والقيود المفروضة على واجهة المستخدم لحماية العمليات الحساسة. لا يعتمد هذا العقد على أتمتة المتصفح، بل يمثل التزامات واجهة المستخدم وتجربة المستخدم (UX) المتوقعة التي يفرضها النظام الخلفي (Backend).

# النطاق
يشمل هذا العقد كافة الإجراءات التشغيلية التي تتطلب تأكيداً من المشغل أو استخدام رموز تنفيذ (Execution Tokens) لضمان السلامة.

# القواعد العامة

| القاعدة | السلوك المتوقع |
| :--- | :--- |
| **الحالة الافتراضية** | الأزرار الأساسية للعمليات الحساسة تكون **معطلة** (Disabled) حتى يتم استيفاء كافة شروط الأمان. |
| **التأكيد النصي** | يجب على المشغل كتابة نص تأكيدي مطابق تماماً (حساس لحالة الأحرف اللاتينية). |
| **Execution Token** | يتم إصداره عبر `issue_operation_execution_token` فوراً قبل التنفيذ؛ ويجب أن يطابق البصمة الحالية (Fingerprint) لقاعدة البيانات. |
| **الرموز منتهية الصلاحية** | إظهار خطأ صريح عند اكتشاف `Stale token`؛ ويُمنع إعادة المحاولة آلياً؛ يجب طلب رمز جديد. |
| **Maintenance Mode** | عندما تكون حالة النظام ليست `NORMAL`؛ يتم حظر كافة عمليات الاستيراد، الكتابة، الإغلاق المالي، الأرشفة، والمزامنة. |
| **النزاهة (Integrity)** | الالتزام بسياسة `INTEGRITY_BLOCKS_OPERATION` والحالات الحرجة (CRITICAL) حسب جدول العمليات. |

# العمليات الحساسة

## 1. استعادة النسخة الاحتياطية (Restore Backup)

| الحقل | القيمة |
| :--- | :--- |
| **نص التأكيد** | `RESTORE` (بالأحرف اللاتينية الكبيرة) |
| **رمز التنفيذ** | مطلوب (`operation: restore`) |
| **الصلاحيات** | المسؤول (Admin) فقط |
| **حظر السلامة** | حالات `Corrupted` أو `Critical` |
| **إعادة المحاولة** | إصدار رمز جديد بعد كل محاولة فاشلة؛ يُمنع إعادة المحاولة التلقائية. |
| **تجربة المستخدم** | إظهار الخطأ بشكل مضمن؛ قد يحتاج التطبيق لإعادة التشغيل عند النجاح. |

---

## 2. أرشفة السنة المالية (Archive Fiscal Year)

| الحقل | القيمة |
| :--- | : :--- |
| **نص التأكيد** | `ARCHIVE` |
| **رمز التنفيذ** | مطلوب (`operation: archive`) |
| **الصلاحيات** | `ManageFiscalYear` (سير عمل مسؤول الولاية) |
| **حظر السلامة** | حالات `Corrupted` أو `Critical` |
| **العوائق** | أي نتائج تشغيلية من فئة **CRITICAL** |
| **تجربة المستخدم** | عرض الرسائل التقنية باللغة العربية؛ الحفاظ على قائمة السنوات دون تغيير عند الفشل. |

---

## 3. إغلاق السنة المالية (Close Fiscal Year)

| الحقل | القيمة |
| :--- | :--- |
| **نص التأكيد** | **رقم السنة المالية المفتوحة** (مثلاً `2025`) |
| **رمز التنفيذ** | مطلوب (`operation: close`) |
| **الصلاحيات** | `ManageFiscalYear` |
| **حظر السلامة** | حالات الحظر المالي القياسية |
| **العوائق** | يوصى بحل النتائج الحرجة (CRITICAL) أولاً قبل الإغلاق. |
| **تجربة المستخدم** | عرض رسائل التحقق/السلامة؛ منع الإغلاق الجزئي في الواجهة. |

---

## 4. استيراد حزمة تاريخية (Import Historical Package)

| الحقل | القيمة |
| :--- | :--- |
| **نص التأكيد** | `IMPORT-HISTORICAL` |
| **رمز التنفيذ** | مطلوب (`operation: import_historical`) |
| **الصلاحيات** | صلاحية الاستيراد + سياسة نوع العقدة |
| **حظر السلامة** | وضع الصيانة، أو استهداف سنة مؤرشفة |
| **إعادة المحاولة** | يدوية فقط بعد معالجة الحزمة أو الطوبولوجيا |

# التحقق من الجاهزية والتشخيص (Diagnostics)
*   **الإجراءات**: `verify_deployment_readiness`, `verify_operational_consistency`, `run_operational_analysis`.
*   **الصلاحيات**: `ViewSystemHealth`.
*   **التأكيد**: لا يتطلب تأكيداً نصياً لأن العمليات للقراءة فقط.

# المصدر الموثوق للنظام (Backend Source of Truth)
تعتمد واجهة المستخدم في قراراتها على الخدمات الخلفية التالية:
*   **جاهزية النشر**: `DeploymentReadinessService`.
*   **وضع الصيانة**: `SystemMaintenanceState`.
*   **الجلسات التشغيلية**: `OperationalSessionService`.
*   **التحقق من الانحراف**: `OperationalConsistencyVerifier`.
