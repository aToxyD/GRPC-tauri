# قائمة التحقق للنشر التجريبي (Trial Deployment Checklist)

# الهدف
توفير قائمة مرجعية لضمان إعداد ونشر النظام بشكل صحيح وآمن في البيئات التجريبية أو الإنتاجية.

# النطاق
يطبق قبل وأثناء عملية النشر الأولي للعقدة.

# خطوات التنفيذ

## أولاً: ما قبل النشر (Pre-Deployment)
- [ ] ضبط متغير البيئة `GRPC_ENV=production`.
- [ ] توليد مفتاح تطبيق فريد `GRPC_APP_KEY` (باستخدام `age-keygen`).
- [ ] توليد مفتاح توقيع فريد `GRPC_PACKAGE_SIGNING_KEY` (قيمة **Base64** تمثل **32 بايت تماماً** بعد فك الترميز).
- [ ] تشغيل `bun run check:arch` والتأكد من نجاح كافة الفحوصات المعمارية.
- [ ] تشغيل `cargo test` والتأكد من نجاح كافة الاختبارات.

## ثانياً: النشر (Deployment)
- [ ] تثبيت الملف التنفيذي المجمع على الجهاز المستهدف.
- [ ] التحقق من تهيئة قاعدة البيانات (التأكد من إنشاء ملف `grpc.db`).
- [ ] تسجيل معرف العقدة (Node ID) ونوعها (Unit أو Wilaya).

## ثالثاً: التحقق (Verification)
- [ ] إنشاء "تقرير يومي" تجريبي للتأكد من عمل واجهة الإدخال.
- [ ] تصدير "حزمة مزامنة" (Sync Package) والتحقق من تشفيرها.
- [ ] تشغيل `verify_audit_chain` للتأكد من أن عملية الـ Hashing الأولية صحيحة.

# ملاحظات السلامة
يجب حفظ المفاتيح المولدة في مكان آمن ومنفصل عن الجهاز المنشور عليه النظام لضمان إمكانية الاسترداد في حالات الطوارئ.
