# Runbook الأمني: إدارة مفاتيح الإنتاج (Production Keys)

# الهدف
تحديد المتطلبات والإجراءات اللازمة لضبط مفاتيح الأمان في بيئة الإنتاج لضمان عمل النظام وفق معايير التشفير والنزاهة المطلوبة.

# النطاق
يطبق هذا الدليل عند إعداد ونشر النظام في بيئة الإنتاج الفعلية.

# المتطلبات الإلزامية
عند ضبط متغير البيئة `GRPC_ENV=production`؛ سيفشل النظام في العمل (Fail-Closed) ولن يبدأ التشغيل ما لم يتم ضبط المتغيرات التالية بشكل صحيح:

| المتغير | القاعدة | الغرض التقني |
| :--- | :--- | :--- |
| `GRPC_APP_KEY` | يجب أن يكون Identity صالحاً لـ `age` (يبدأ بـ `AGE-SECRET-KEY-1...`) | التشفير المتدفق (Streaming Encryption) للنسخ الاحتياطية والبيانات المحلية. |
| `GRPC_PACKAGE_SIGNING_KEY` | **Base64** لنص عشوائي بطول **32 بايت تماماً** بعد فك الترميز | توليد والتحقق من HMAC لحزم المزامنة لضمان النزاهة. |

> **ملاحظة صارمة (Release)**: المفاتيح الاحتياطية المدمجة للتطوير تُضمَّن في **حِزم التطوير فقط** (`#[cfg(debug_assertions)]`). لا توجد أي قيمة افتراضية أو احتياطية في حِزم الإصدار (Release)؛ غياب أي مفتاح يُوقف تشغيل النظام فوراً.

# خطوات التنفيذ

## 1. توليد المفاتيح (Key Generation)

### أ. توليد `GRPC_APP_KEY`
استخدم أداة `age-keygen` الرسمية لتوليد هوية جديدة:
```bash
age-keygen -o key.txt
```
انسخ المفتاح السري الذي يبدأ بـ `AGE-SECRET-KEY-1...` واحتفظ به في مكان آمن ومشفر.

### ب. توليد `GRPC_PACKAGE_SIGNING_KEY`
قم بتوليد 32 بايت عشوائية قوية (Entropy عالي) ثم قم بترميزها **Base64**. **يجب** أن يكون هذا المفتاح متطابقاً بين كافة العقد (الولاية والوحدات) لتمكين تبادل البيانات.

```bash
openssl rand -out /tmp/signing-key.bin 32
base64 -w0 /tmp/signing-key.bin
```
ضع القيمة الناتجة (سطر واحد Base64 يمثل 32 بايت تماماً) في متغير `GRPC_PACKAGE_SIGNING_KEY`.

## 2. ضبط البيئة
1.  تأكد من ضبط `GRPC_ENV=production`.
2.  اضبط متغيرات البيئة في نظام التشغيل (OS Level Environment Variables).
3.  **يُحظر تماماً** حفظ هذه المفاتيح داخل كود المصدر أو في ملفات غير محمية.

# حالات الفشل (Fail-Closed Behavior)
*   **في الإنتاج**: لا توجد مفاتيح افتراضية أو بديلة (No Fallback). فقدان المفتاح أو عدم صلاحيته يؤدي لتوقف النظام فوراً قبل بدء التشغيل.
*   **في التطوير**: يسمح النظام باستخدام مفاتيح مدمجة لأغراض الاختبار فقط (في حِزم debug حصراً)، مع إظهار تحذيرات أمنية.

# فئات الخطأ (Missing vs Malformed)
يُعامل النظام حالتين منفصلتين من أخطاء المفاتيح عند ضبط `GRPC_ENV=production`:
| الحالة | النوع | النتيجة |
| :--- | :--- | :--- |
| المتغير غير موجود أصلاً | **Configuration error** | يتوقف الإقلاع برسالة "المفتاح مطلوب" |
| المتغير موجود لكنه غير صالح (بادئة خاطئة / Base64 غير صالح / حجم غير 32 بايت) | **Validation error** | يتوقف الإقلاع برسالة "المفتاح غير صالح" |

التمييز بين الحالتين يمنع استبدال غياب المفتاح بخطأ صامت في التكوين.

# ملاحظات السلامة
*   في حال فقدان `GRPC_APP_KEY`؛ لن تتمكن من استعادة أي نسخة احتياطية مشفرة.
*   في حال تسرب `GRPC_PACKAGE_SIGNING_KEY`؛ يجب تدوير المفتاح (Rotate Key) فوراً في كافة العقد لمنع هجمات التلاعب بالبيانات.

# التحقق
شغل التطبيق وراقب مخرجات `stderr`. إذا بدأ التطبيق وظهرت واجهة تسجيل الدخول دون خروج مفاجئ، فهذا يعني نجاح عملية التحقق من المفاتيح.
