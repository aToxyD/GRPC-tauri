# Runbook: استعادة حزم المزامنة (Sync Package Recovery)

# الهدف
توفير إجراءات لاستعادة البيانات في حال فقدان حزمة مزامنة أو تعرضها للتلف أثناء النقل بين العقد.

# النطاق
يطبق عند فشل استلام أو قراءة حزمة مزامنة مشفرة.

# خطوات التنفيذ

## 1. العقدة المصدر (Source Node)
قم بإعادة عملية التصدير (Export) للفترة المعنية (شهر/يوم) مرة أخرى لتوليد حزمة جديدة.

## 2. الذرية (Atomicity)
بفضل منطق `ImportTransactionRunner` الذري، ستقوم العقدة المستقبلة بتجاهل السجلات المكررة بأمان في حال تمت معالجة بعضها مسبقاً، مما يضمن اتساق البيانات دون تكرار.

## 3. التحقق من سلامة الحزمة
استخدم منطق التحقق الداخلي (Verification Logic) لفحص الحزمة يدوياً قبل محاولة الاستيراد النهائية.

# ملاحظات السلامة والوقاية
*   استخدم حصراً ملفات بامتداد `.sync` لعمليات النقل.
*   **يُمنع** إعادة تسمية الملفات أو تعديل المحتويات الثنائية (Binary) لملفات `.sync`؛ لأن ذلك سيكسر التوقيع التشفيري (HMAC).
