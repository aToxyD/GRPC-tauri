# Runbook: التحقيق في فشل الاستيراد (Import Failure Investigation)

# الهدف
توفير خطوات عملية للتحقيق في أسباب فشل استيراد حزم المزامنة (Sync Packages) واستعادة العمليات.

# النطاق
يطبق عند ظهور أخطاء أثناء محاولة استيراد حزمة بيانات.

# خطوات التنفيذ

## 1. فحص السجلات
قم بتصفية سجلات التدقيق (Audit Logs) للبحث عن الإجراءات من نوع `ImportRejected`.

## 2. استعلام قاعدة البيانات
يمكن لمسؤول النظام تشغيل الاستعلام التالي لرؤية الأسباب المحددة للفشل:
```sql
SELECT * FROM import_audit_events WHERE event_type = 'Rejected' ORDER BY timestamp DESC LIMIT 5;
```

## 3. الأسباب الشائعة
*   **InvalidSignature**: عدم تطابق مفتاح التوقيع (Signing Key) أو تعرض الحزمة للتلاعب.
*   **DuplicatePackage**: تفعيل حماية الإعادة (Replay Protection) لمحاولة استيراد حزمة مكررة.
*   **SchemaMismatch**: الحزمة صادرة من إصدار قديم أو أحدث غير مدعوم حالياً.
*   **IntegrityFailure**: عدم تطابق الـ Hash (احتمال وجود تلف في الملف).

# إجراءات الحل
*   التأكد من أن كلا العقدتين (المرسلة والمستقبلة) تستخدمان نفس مفتاح `GRPC_PACKAGE_SIGNING_KEY`.
*   التحقق مما إذا كانت الحزمة قد تم استيرادها مسبقاً.
*   إعادة تصدير الحزمة من العقدة المصدر في حال الشك بحدوث تلف أثناء النقل.
