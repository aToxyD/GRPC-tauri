# Runbook: تهيئة المسؤول الافتراضي (Admin Bootstrap)

# الهدف
توثيق سلوك تهيئة حساب المسؤول الافتراضي `admin` عند الإقلاع، وضمان ثبات (Idempotency) هذه العملية حتى لا تُعاد تهيئة بيانات الاعتماد (Credentials) في أي إقلاع لاحق.

# النطاق
سلوك إقلاع التطبيق فقط (`create_default_admin`)؛ تغيير كلمات المرور لاحقاً يتم عبر مسار إداري مستقل.

# السلوك الموثق (Bootstrap Semantics)

1. **الإقلاع الأول (First Startup)**
   - عند إنشاء قاعدة بيانات جديدة لأول مرة، يقوم النظام بإنشاء حساب مسؤول افتراضي:
     - اسم المستخدم: `admin`
     - كلمة المرور الافتراضية: `admin`
   - يتم ذلك مرة واحدة فقط ضمن مسار التهيئة (`ConnectionFactory::new` / `new_with_path`).

2. **الإقلاعات اللاحقة (Subsequent Startups)**
   - إذا وُجد حساب باسم `admin` بالفعل، **لا يُلمس أي من بيانات الاعتماد**:
     - لا يُعاد توليد `password_hash`.
     - لا يُعدَّل `created_at` أو `updated_at`.
     - لا تُنشأ صفوف إضافية.
   - العملية محمية ذرياً عبر `INSERT ... ON CONFLICT(username) DO NOTHING`؛ التكرار المتعدد للتهيئة لا يُنشئ سوى صف واحد.

3. **لا إعادة تهيئة أبداً (Never Reset)**
   - إعادة تشغيل التطبيق **لا تعيد** كلمة المرور الافتراضية.
   - إذا غُيّرت كلمة مرور المسؤول، تبقى القيمة الجديدة سارية عبر عمليات الإقلاع المتكررة.
   - الحساب المحذوف (Soft Delete) باسم `admin` لا يُعاد إحياؤه بكلمة مرور افتراضية معروفة.

4. **استرداد كلمة المرور (Recovery)**
   - استرداد/تعديل كلمة المرور يتم عبر **مسار إداري مستقل** بعد تسجيل الدخول، وليس عبر إعادة التهيئة عند الإقلاع:
     - `change_password` (أمر `change_password` في `commands/auth.rs`).
   - لا يوجد مسار إقلاع يعيد تعيين كلمة المرور.

# الضمان الأمني
السلوك أعلاه يمثل ثابتاً معمارياً (Invariant):

> **الإقلاع يجب أن يكون Idempotent فيما يتعلق ببيانات اعتماد المسؤول.**

أي تغيير مستقبلي في مسار التهيئة يجب أن يحافظ على هذا الثابت؛ الاختبارات المكفِّلة موجودة في
`src-tauri/tests/admin_bootstrap_persistence.rs`.

# التحقق
1. أنشئ قاعدة بيانات جديدة وسجّل الدخول بـ `admin` / `admin`.
2. غيّر كلمة المرور.
3. أعد تشغيل التطبيق ثم سجّل الدخول بكلمة المرور الجديدة.
4. تأكد أن كلمة المرور الافتراضية لم تعد تعمل.
