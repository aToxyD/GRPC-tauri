# دليل المزامنة (Sync Runbook)

# الهدف
يهدف هذا الدليل إلى توضيح المسار الإجرائي لتبادل البيانات بين عقدة **الوحدة** (Unit) وعقدة **الولاية** (Wilaya) باستخدام حزم المزامنة المعتمدة، لضمان استمرارية واتساق البيانات عبر الشبكة.

# النطاق
يغطي هذا الدليل عمليات تصدير واستيراد حزم المزامنة (`.sync`) والتعامل مع حالات الفشل التشغيلية.

# القواعد الأساسية للمزامنة
*   المزامنة تتم **حصراً** عبر ملفات الحزم المشفرة والموقعة (`.sync`).
*   يُمنع استخدام ملفات CSV أو Excel لاستيراد البيانات؛ حيث تقتصر ملفات Excel على التقارير البشرية والطباعة فقط.
*   يعتمد النظام سياسة **Fail-Closed**؛ أي أن أي شك في نزاهة الحزمة يؤدي لرفضها فوراً.

# مصفوفة تبادل البيانات

| الجهة المصدرة | نوع البيانات | الامتداد | الجهة المستوردة |
| :--- | :--- | :--- | :--- |
| **الوحدة (Unit)** | تقارير الاستهلاك والطلبات | `.sync` | **الولاية (Wilaya)** |
| **الولاية (Wilaya)** | كتالوج المنتجات والأسعار المركزية | `.sync` | **الوحدة (Unit)** |

# مسببات فشل الاستيراد (Rejection Criteria)
يرفض النظام حزم المزامنة في الحالات التالية:
*   **Replay Attack**: استيراد حزمة تم معالجتها سابقاً (تطابق `package_id`).
*   **Integrity Failure**: عدم تطابق الـ Hash مع المحتوى (تلف أو تلاعب).
*   **Invalid Signature**: فشل التحقق من توقيع Ed25519 لهوية العقدة المُصدِرة (مفتاح مختلف، هوية غير موثوقة، أو تلاعب).
*   **Version Mismatch**: عدم توافق إصدار بروتوكول المزامنة.
*   **Signer Not Trusted**: العقدة المصدرة غير مدرجة في قائمة الثقة.

# التشخيص السريع (Troubleshooting)

| كود الخطأ | السبب المحتمل | الإجراء المطلوب |
| :--- | :--- | :--- |
| `PACKAGE_ALREADY_IMPORTED` | محاولة استيراد ملف مكرر | تأكد من استيراد أحدث نسخة تم تصديرها. |
| `SIGNATURE_INVALID` | توقيع Ed25519 غير صالح أو مُصدِر غير موثوق | تحقق من هوية العقدة المُصدِرة (مرساة الثقة WILAYA) في Identity Store. |
| `INTEGRITY_CHECK_FAILED` | تلف مادي للملف أثناء النقل | أعد عملية التصدير والنقل باستخدام وسيط تخزين سليم. |
| `SIGNER_NOT_TRUSTED` | هوية المصدر غير موثوقة | راجع شهادات الهوية المثبتة (مرساة الثقة WILAYA / Root) في شاشة الهوية. |

# إجراءات التحقق
*   **`get_sync_security_diagnostics`**: يعرض الحالة الأمنية لمفاتيح المزامنة ووضع التشغيل.
*   **`sync_preflight_check`**: فحص آلي لجاهزية النظام قبل بدء الاستيراد.

# السجلات والتدقيق
يتم تسجيل كل محاولة استيراد (ناجحة أو فاشلة) في سجل التدقيق (Audit Log) مع إرفاق بصمة الحزمة (Package Fingerprint) وهوية المشغل.
