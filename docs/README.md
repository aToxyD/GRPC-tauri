# توثيق مشروع GRPC

يحتوي هذا الدليل على التوثيق الشامل لمشروع GRPC، منظماً حسب الفئة والغرض.

## الهيكل التنظيمي

- **[architecture/](./architecture/)**: سجلات القرارات المعمارية (ADRs) النشطة ووثائق المعمارية.
- **[frontend/](./frontend/)**: إرشادات وعقود الواجهة الأمامية وحوكمتها.
- **[governance/](./governance/)**: محرك الحوكمة وملاحظات الامتثال.
- **[operator/](./operator/)**: أدلة التشغيل، Runbooks، وقوائم التحقق للمسؤولين والمشغلين اليوميين.
- **[runbooks/](./runbooks/)**: أدلة التشغيل الفنية (Technical Runbooks).
- **[security/](./security/)**: توثيق الأمن ونماذج التهديدات.
- **[technical/](./technical/)**: توثيق تقني متعمق يتعلق بالأمن، المعمارية (Architecture)، وإرشادات المطورين.

## التنقل

- ابدأ بـ **[دليل المشغل (Operator Manual)](./operator/OPERATOR_MANUAL.md)** للحصول على تعليمات الاستخدام اليومي.
- استشر **[التوثيق التقني (Technical Documentation)](./technical/TECHNICAL_DOCUMENTATION.md)** للتعرف على الأجزاء الداخلية للنظام.
- ارجع إلى **[Runbook إغلاق السنة المالية](./operator/FISCAL_YEAR_CLOSURE_RUNBOOK.md)** للتعامل مع الانتقالات المالية السنوية.
- اطلع على **[إجراءات التشغيل والإيقاف](./operator/STARTUP_AND_SHUTDOWN_PROCEDURES.md)** لضمان سلامة النظام.
- راجع **[مصفوفة تصعيد الحوادث](./operator/INCIDENT_ESCALATION_MATRIX.md)** عند حدوث حالات طوارئ.


## معجم المصطلحات التقنية

يعمل هذا المعجم كمرجع موحد للمصطلحات المستخدمة عبر كافة وثائق المشروع لضمان الدقة والاتساق.

| المصطلح بالعربية | المصطلح التقني (English) | المعنى المختصر |
| :--- | :--- | :--- |
| نسخة احتياطية | Backup | عملية حفظ البيانات لاسترجاعها لاحقاً. |
| استعادة | Restore | عملية إعادة البيانات من نسخة احتياطية. |
| Snapshot | Snapshot | لقطة ثابتة للبيانات في لحظة زمنية معينة. |
| سلامة | Integrity | التأكد من أن البيانات لم يتم تعديلها أو إتلافها. |
| تدقيق | Audit | تتبع وتسجيل العمليات لغرض المراجعة والتحقق. |
| أرشفة | Archive | نقل البيانات غير النشطة إلى تخزين طويل الأمد. |
| انتقال السنة المالية | Fiscal Transition | عملية إغلاق السجلات المالية لسنة وفتح أخرى جديدة. |
| حزمة إغلاق السنة المالية | Fiscal Closure Package | الحزمة البرمجية والمشفرة التي تحتوي على بيانات الإغلاق المالي. |
| Replay Protection | Replay Protection | آلية تمنع إعادة تنفيذ العمليات المسجلة مسبقاً بشكل غير قانوني. |
| Checkpoint | Checkpoint | نقطة مرجعية لضمان كتابة البيانات من WAL إلى ملف القاعدة الرئيسي. |
| تحقق | Validation | التأكد من صحة البيانات أو العمليات وفق قواعد محددة. |
| تفويض | Authorization | منح صلاحيات محددة للمشغل لتنفيذ عملية معينة. |
| المشغل | Operator | الشخص المسؤول عن إدارة واستخدام النظام. |
| تلف | Corruption | حدوث خطأ غير مقصود يؤدي لفقدان سلامة البيانات. |
| فشل | Failure | عدم قدرة النظام أو المكون على أداء وظيفته المطلوبة. |
| استرجاع | Recovery | العودة إلى حالة تشغيلية مستقرة بعد حدوث فشل. |
| Transaction | Transaction | وحدة عمل برمجية يتم تنفيذها بالكامل أو لا يتم تنفيذها إطلاقاً. |
| مزامنة | Sync | عملية توحيد البيانات بين مصادر مختلفة. |
| حزمة | Package | وحدة مغلفة من البيانات أو البرمجيات. |
| سياسة الاحتفاظ | Retention Policy | القواعد التي تحدد مدة الاحتفاظ بالبيانات أو النسخ الاحتياطية. |
| سجل | Registry | قاعدة بيانات أو قائمة مركزية لتخزين المعلومات أو الإعدادات. |
| سير العمل | Workflow | تسلسل الخطوات والإجراءات المتبعة لإتمام مهمة معينة. |
| Fail-Closed | Fail-Closed | سياسة أمنية تضمن إغلاق النظام ومنع الوصول عند حدوث فشل. |
| WAL | WAL | (Write-Ahead Logging) تقنية تسجيل التغييرات قبل كتابتها فعلياً. |
| Audit Chain | Audit Chain | سلسلة متصلة وغير قابلة للتلاعب من سجلات التدقيق. |
| Structured Logging | Structured Logging | تسجيل الأحداث بتنسيق منظم يسهل تحليله برمجياً. |
| Offline-first | Offline-first | نهج تصميمي يضمن عمل النظام بكفاءة دون الحاجة لاتصال دائم. |
| Atomic Transaction | Atomic Transaction | عملية تضمن التنفيذ الكامل أو الإلغاء الكامل دون حالة وسيطة. |
| Sync Package | Sync Package | حزمة بيانات مشفرة تستخدم لنقل البيانات بين العقد. |
| Restore Flow | Restore Flow | التسلسل الإجرائي لعملية استعادة البيانات. |
| Rate Limiter | Rate Limiter | آلية للتحكم في عدد العمليات المنفذة خلال وحدة زمنية. |
| Secure Delete | Secure Delete | الحذف الآمن للبيانات لضمان عدم إمكانية استرجاعها. |
| ADR | ADR | (Architectural Decision Record) سجل يوثق القرارات المعمارية الهامة. |
| Hash / HMAC | Hash / HMAC | خوارزميات لضمان سلامة البيانات والتحقق من الهوية. |
| Backup Lifecycle | Backup Lifecycle | دورة حياة النسخة الاحتياطية من الإنشاء إلى الأرشفة أو الحذف. |
